v6.2 — console filter + fixes
✨ New

    Console Filter — new module in miscellaneous → config. Leaves only kill/miss logs in the console, hiding all other spam (including engine messages and third-party modules). Works via con_filter_enable / con_filter_text with the [K/M] prefix.

        Kill logs: [K/M] KILL <nickname>

        Miss logs: [K/M] MISS target N cycle side K (resolver) / [K/M] MISS silent aim — 1.0s no hit (silent aim)

        Original con_filter_* values are saved and restored when the checkbox is turned off and on on_unload

        Re-apply Filter button in case another module resets the cvar

    Silent Aim miss detection — if SA is enabled without the resolver, a miss log is written after 1.0s of continuous fire with no player_hurt

    Kill log in player_death — victim's nickname is printed to console with the [K/M] prefix

🔧 Fixes

    p:is_valid() — kept, confirmed by En1gma documentation

    find_plausible_key — info.writable check now uses == nil or truthy, so the key is found even if the writable field is missing at runtime (not in docs)

    imgui.get_display_size → render.get_screen_size — get_display_size doesn't exist in the API; intro and menu could fail to render
